# Smart Home Design Configurator — Working Glossary

เอกสารนี้รวบรวมคำศัพท์กลางของผลิตภัณฑ์ เพื่อให้เจ้าของโปรเจกต์ สถาปนิก นักออกแบบ และทีมพัฒนาใช้ความหมายตรงกัน โดยจะปรับให้สมบูรณ์ระหว่างการวางแผน

## คำศัพท์หลัก

### Configurator

ประสบการณ์แบบทีละขั้นที่ช่วยผู้ใช้เลือกและจัดระเบียบความต้องการสำหรับบ้านสร้างใหม่ ไม่ใช่เครื่องมือสร้างแบบก่อสร้างอัตโนมัติ

### Configuration

ชุดคำตอบเกี่ยวกับบ้านที่ผู้ใช้เลือก เช่น สไตล์ จำนวนชั้น ห้อง พื้นที่ วัสดุ ที่ดิน งบประมาณ และลำดับความสำคัญ โดยไม่รวมข้อมูลส่วนตัวของ Lead

### Concept Preview

ภาพแนวคิดที่จับคู่จากตัวเลือกของผู้ใช้ เพื่อช่วยสื่อสารทิศทางของบ้าน ไม่ใช่ภาพบ้านจริง แบบสถาปัตยกรรม หรือคำรับรองว่าผลลัพธ์สุดท้ายจะเหมือนภาพ

สำหรับ MVP ภาพมาจาก Curated Concept Library ที่ KSB ตรวจรับแล้วและจับคู่ตาม Style จำนวนชั้น Material Mood หลังคา และองค์ประกอบสำคัญ ไม่สร้างภาพ AI แบบเรียลไทม์

### Curated Concept Asset

ภาพอ้างอิงทิศทางการออกแบบที่ผ่านการตรวจคุณภาพ ความสมเหตุสมผล สิทธิ์การใช้งาน และขอบเขตการแชร์แล้ว ต้องมี Metadata และเวอร์ชันเพื่อใช้จับคู่และตรวจสอบย้อนหลัง

### Free Preview Result

ผลลัพธ์เบื้องต้นที่ผู้ใช้เห็นได้ทันทีโดยไม่กรอกข้อมูลส่วนตัว ประกอบด้วย Concept Preview สเปกหลัก และช่วงงบประมาณแบบกว้าง

### Full Project Report

รายงานฉบับเต็มที่ปลดล็อกหลังผู้ใช้ยินยอมส่งข้อมูลติดต่อ ประกอบด้วยรายละเอียด Requirement การประมาณราคาแบบละเอียด PDF การบันทึกโครงการ และทางเลือกปรึกษาสถาปนิก

### Preliminary Estimate

ช่วงราคาประเมินเพื่อช่วยวางกรอบโครงการ ไม่ใช่ BOQ ใบเสนอราคา หรือราคาที่มีผลผูกพัน

### Construction Estimate

ช่วงค่าก่อสร้างอาคารที่คำนวณจากพื้นที่ใช้สอย ระดับวัสดุ ความซับซ้อน ทำเล และปัจจัยที่ได้รับการยืนยันว่าอยู่ในสูตร โดยต้องระบุรายการที่รวมและไม่รวม

### Usable Area

พื้นที่ที่ผู้อยู่อาศัยใช้งานจริง ใช้เพื่อสื่อสาร Requirement แต่ไม่ควรนำไปคูณราคาต่อตารางเมตรโดยตรงหากยังไม่ได้แปลงเป็นพื้นที่ก่อสร้างตามกติกาที่รับรอง

### Construction Floor Area (CFA)

พื้นที่ก่อสร้างรวมที่ระบบใช้เป็นฐานคำนวณราคา รวมพื้นที่ภายในและพื้นที่ประกอบตามกติกาที่ KSB รับรอง เช่น บันได ระเบียง เฉลียง ที่จอดรถมีหลังคา และพื้นที่ระบบ โดยอาจใช้น้ำหนักต่างกันตามประเภทพื้นที่

### Room Program

รายการจำนวนและประเภทห้อง รวมถึงความต้องการใช้งานหลักของบ้าน ใช้เป็นต้นทางในการแนะนำพื้นที่และเป็นส่วนหนึ่งของ Full Project Report สำหรับนำไปคุยกับสถาปนิก

### Recommended Usable Area

พื้นที่ใช้สอยที่ระบบแนะนำจาก Room Program และระดับความกว้างที่ผู้ใช้เลือก เป็นคำแนะนำที่แก้ไขได้ ไม่ใช่ข้อกำหนดของแบบก่อสร้าง

### Area Override

พื้นที่ที่ผู้ใช้แก้ไขจากคำแนะนำของระบบ ต้องเก็บทั้งค่าเดิมและค่าที่แก้ พร้อมตรวจสอบว่าพื้นที่ใหม่ยังรองรับ Room Program ได้สมเหตุสมผลหรือไม่

### Material Level

ระดับคุณภาพและความซับซ้อนของวัสดุ งานระบบ และรายละเอียดติดตั้งที่ใช้กำหนดช่วงราคาฐาน ไม่ใช่การเลือกแบรนด์วัสดุรายชิ้น และต้องมีคำอธิบายสิ่งที่ผู้ใช้จะได้รับในแต่ละระดับ

MVP ใช้ 3 ระดับ ได้แก่ Select, Premium และ Signature ผู้ใช้เลือกระดับหลักหนึ่งระดับสำหรับทั้งโครงการ ส่วนรายละเอียดรายหมวดมีไว้ช่วยเปรียบเทียบและอธิบายสมมติฐาน

### Material Mood

ภาพและชุดตัวอย่างที่สื่อบรรยากาศ คุณภาพ และแนวทางวัสดุของ Material Level ไม่ใช่ Specification หรือคำรับประกันยี่ห้อ รุ่น สี และวัสดุที่จะใช้จริง

### Province Factor

ตัวปรับค่าก่อสร้างตามจังหวัดที่สร้างจากข้อมูลวัสดุ ค่าแรง และค่าขนส่งที่ผ่านการตรวจรับแล้ว ไม่รวมข้อจำกัดเฉพาะหน้างาน เช่น ทางเข้าแคบ เกาะ หรือพื้นที่ลาดชัน

### Site Access Profile

ชุดคำตอบแบบกดเลือกเกี่ยวกับการเข้าถึงที่ดิน สภาพพื้นที่ และข้อจำกัดการขนส่ง ใช้เพื่อเพิ่ม Allowance หรือขยายช่วงราคา โดยไม่ต้องขอที่อยู่หรือพิกัดจริงก่อน Free Preview

### Site Logistics Allowance

ช่วงงบเผื่อสำหรับข้อจำกัดเฉพาะหน้างาน เช่น รถใหญ่เข้าไม่ถึง การขนส่งขึ้นเกาะ หรือพื้นที่ลาดชัน แสดงแยกจาก Province Factor และอาจเป็นรายการรอตรวจสอบหากข้อมูลยังไม่เพียงพอ

### Price Book Version

รหัสรุ่นของฐานราคาและกฎคำนวณที่ถูกเผยแพร่ให้ Pricing Engine ใช้ ทำให้ผลประเมินสามารถตรวจสอบย้อนหลังได้แม้ฐานราคาจะเปลี่ยนในอนาคต

### Confidence Level

ระดับความครบถ้วนของข้อมูลที่ใช้ประเมิน ไม่ใช่คำรับประกันความแม่นยำ แบ่งเบื้องต้นเป็น Concept, Brief และ Pre-design Review เพื่อกำหนดว่าระบบควรแสดงช่วงกว้างเพียงใด

### Design & Professional Fee

ช่วงค่าออกแบบและบริการวิชาชีพที่เกี่ยวข้องกับการทำให้ Requirement กลายเป็นแบบและข้อมูลพร้อมพัฒนาโครงการ การนำเสนอจะอธิบายขอบเขตงานและคุณค่าควบคู่กับราคา ไม่รวมซ่อนไว้ในค่าก่อสร้าง

สำหรับ MVP ขอบเขตนี้รวมงานสถาปัตยกรรม โครงสร้าง ระบบไฟฟ้า ระบบสุขาภิบาล แบบขออนุญาต และแบบก่อสร้างตามมาตรฐาน KSB โดยไม่รวมค่าควบคุมงานก่อสร้าง งานออกแบบตกแต่งภายใน และงานออกแบบภูมิสถาปัตยกรรม

### Construction Supervision Fee

ค่าบริการควบคุมหรือตรวจติดตามงานก่อสร้างตามขอบเขตที่ตกลง เป็นบริการแยกจาก Design & Professional Fee และไม่ถูกบวกในผลประเมินของ MVP โดยอัตโนมัติ

### Additional Budget Items

รายการค่าใช้จ่ายที่เจ้าของโครงการอาจต้องเตรียมเพิ่มนอกเหนือจากค่าก่อสร้างและค่าออกแบบ เช่น งานเฉพาะที่ดิน งานภายนอก เฟอร์นิเจอร์ หรือค่าธรรมเนียม โดยจะแยกสิ่งที่คำนวณได้ สิ่งที่ใช้ Allowance และสิ่งที่ยังไม่รวม

### Special Feature

องค์ประกอบที่ผู้ใช้ต้องการและมีผลต่องบสูงกว่าบ้านทั่วไป เช่น สระว่ายน้ำ ลิฟต์ Smart Home Solar EV Charger Double Volume หรือกระจกขนาดใหญ่ แยกออกจาก Material Level เพื่อป้องกันการคิดต้นทุนซ้ำ

### Allowance Range

ช่วงงบเผื่อสำหรับรายการที่ทราบความต้องการแล้วแต่ยังไม่มีแบบหรือสเปกเพียงพอสำหรับคำนวณละเอียด ต้องแสดงสมมติฐานและไม่เรียกว่าใบเสนอราคา

### Project Budget Envelope

กรอบงบรวมที่ระบบสามารถคำนวณได้อย่างรับผิดชอบจากองค์ประกอบที่มีข้อมูลเพียงพอ ไม่ใช่ราคาสุดท้าย และต้องแสดงสมมติฐานพร้อมรายการที่ยังไม่รวม

### Lead

บุคคลที่ส่งข้อมูลติดต่อและ Consent เพื่อรับ Full Project Report หรือขอคำปรึกษา โดยต้องเชื่อมกับ Configuration แต่จัดเก็บแยกจากกัน

### Public Preview

ข้อมูลสรุปที่แชร์ได้โดยไม่เปิดเผยข้อมูลส่วนตัว Detailed Pricing, Full Requirement หรือ Private Notes

### Soft Gate

จุดแลกเปลี่ยนคุณค่าอย่างโปร่งใส ผู้ใช้ได้รับ Free Preview ก่อน และเลือกส่งข้อมูลติดต่อเพื่อรับ Full Project Report โดยไม่ใช้ข้อความหรือรูปแบบที่ทำให้รู้สึกว่าเป็น Lead Trap

## ขอบเขตที่ยืนยันแล้ว

- MVP รองรับการประเมิน “บ้านสร้างใหม่” เท่านั้น
- งานรีโนเวตและต่อเติมอยู่นอกขอบเขตการประเมินราคาของ MVP
- ผลลัพธ์ทั้งหมดเป็นข้อมูลเบื้องต้นสำหรับเริ่มคุยกับสถาปนิก
- งบประมาณต้องแยกค่าก่อสร้าง ค่าออกแบบและบริการวิชาชีพ และค่าใช้จ่ายเพิ่มเติมอย่างโปร่งใส
