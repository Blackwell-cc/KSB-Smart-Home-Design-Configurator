# Preview Additional Views Positioning

## Goal

คงดีไซน์ชุดภาพ “มุมมองเพิ่มเติม” แบบกองภาพซ้อนเดิมในหน้าภาพรวมบ้าน พร้อมจัดตำแหน่งใหม่เพื่อไม่ให้ภาพทับข้อความ Concept Direction ในทุกขนาดหน้าจอ

## Scope

- คงโครงสร้างหลักของหน้า ภาพหลัก ข้อความ และรูปแบบกองภาพเดิม
- ไม่เพิ่มปุ่มหรือพฤติกรรมใหม่ให้ชุดภาพ
- ปรับเฉพาะพื้นที่สำรองของข้อความ ตำแหน่ง และสเกลของชุดภาพตามขนาดหน้าจอ

## Responsive Behavior

- Desktop: สำรองพื้นที่ด้านขวาของข้อความให้กว้างกว่าชุดภาพ และวางชุดภาพชิดมุมขวาล่าง
- Tablet: วางข้อความด้านบนและชุดภาพด้านล่าง พร้อมลดสเกลชุดภาพเพื่อให้มีระยะห่างชัดเจน
- Mobile: วางชุดภาพใต้ข้อความโดยไม่ย่อสเกลเพิ่มเติม และคงไว้ภายในกรอบภาพหลัก
- ทุกขนาดต้องไม่มีการทับกันระหว่างหัวข้อหรือคำอธิบายกับชุดภาพ และไม่มี Horizontal Overflow

## Verification

- Style test ยืนยันค่าพื้นที่สำรองและตำแหน่งหลักของดีไซน์กองภาพเดิม
- Playwright คำนวณพื้นที่ตัดกันระหว่างชุดภาพกับหัวข้อและคำอธิบายที่ความกว้าง 375, 768, 1440 และ 1908 พิกเซล โดยต้องเท่ากับศูนย์
- ตรวจภาพจริงทั้งหน้าจอมือถือและเดสก์ท็อปเพื่อยืนยันลำดับสายตาและระยะห่าง
