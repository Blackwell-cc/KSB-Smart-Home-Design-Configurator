# Preview Additional Views Card Design

## Goal

ปรับส่วน “มุมมองเพิ่มเติม” ในหน้าภาพรวมบ้านให้ภาพตัวอย่างไม่ซ้อนทับข้อความ Concept Direction และสื่ออย่างชัดเจนว่าผู้ใช้สามารถรับภาพเพิ่มเติมได้ผ่านรายงานฉบับเต็ม

## Scope

- คงโครงสร้างหลักของหน้าภาพรวมบ้าน ตำแหน่งภาพหลัก ข้อมูลโครงการ งบประมาณ และส่วน CTA ด้านล่าง
- ปรับเฉพาะพื้นที่คำอธิบาย Concept Direction และชุดภาพมุมมองเพิ่มเติมภายในกรอบภาพหลัก
- ใช้ภาพและข้อมูลเดิม ไม่เพิ่มข้อมูลโครงการหรือระบบ Gallery ใหม่

## Desktop Layout

พื้นที่ด้านล่างของภาพหลักใช้แถบ Gradient เดิม แต่แบ่งเป็น Grid สองคอลัมน์ที่มีขอบเขตชัดเจน:

- ฝั่งซ้ายเป็นข้อความ Concept Direction และกำหนดพื้นที่ให้ยืดหยุ่นตามความกว้าง
- ฝั่งขวาเป็นการ์ด Gallery Teaser แบบกระชับ มีภาพตัวอย่างสามภาพวางซ้อนในกรอบของตนเอง
- ทั้งสองส่วนมีช่องว่างคงที่และไม่ใช้ระยะ Padding เพื่อหลบกัน จึงไม่สามารถซ้อนทับกันได้

## Gallery Teaser

- แสดงภาพตัวอย่างสามมุมในกรอบเดียว โดยจำกัดภาพทั้งหมดให้อยู่ภายในขอบการ์ด
- แสดงจำนวน “+12” เป็น Badge ขนาดเล็กบนชุดภาพ
- ใช้ข้อความหลัก “ดูมุมมองเพิ่มเติม” และข้อความรอง “รับชมในรายงานฉบับเต็ม”
- แสดงลูกศรเพื่อสื่อว่ากดได้
- การ์ดทั้งใบเป็นปุ่มและเปิดขั้นตอน “รับข้อมูลฉบับเต็ม” เดียวกับ CTA หลักด้านล่าง
- มี Hover, Focus และ Press state ที่สุภาพตามโทนทอง ดำ และงาชงอุ่นของ KSB Architect

## Responsive Behavior

- Tablet: ลดขนาดภาพและช่องว่าง โดยยังคง Grid สองคอลัมน์เมื่อพื้นที่เพียงพอ
- Mobile: เปลี่ยนแถบล่างเป็นหนึ่งคอลัมน์ ข้อความอยู่ด้านบน และ Gallery Teaser อยู่ด้านล่างเต็มความกว้าง
- ไม่มีการวางภาพแบบลอยทับข้อความ และต้องไม่มี Horizontal Overflow

## Accessibility

- Gallery Teaser ใช้ `<button type="button">` พร้อมชื่อที่บอกผลของการกดว่าเปิดรายงานฉบับเต็ม
- ภาพตัวอย่างยังมีข้อความทดแทนที่ระบุลำดับมุมมองและสไตล์บ้าน
- Focus state มองเห็นชัด และพื้นที่กดมีความสูงอย่างน้อย 44 พิกเซล
- Reduced motion ปิดการเคลื่อนไหวของการ์ด

## Component Changes

- `AdditionalViews` รับ `onFullReport` และเรียก callback เมื่อผู้ใช้กดการ์ด
- `FreePreview` ส่ง callback เดิมให้ทั้ง Gallery Teaser และ CTA หลัก
- ปรับ CSS ของ `conceptCaption`, `additionalViews`, `viewStack`, `viewThumbnail` และ `viewDetails` ให้ใช้พื้นที่แบบ Grid ที่แยกกัน

## Verification

- Component test ยืนยันว่า Gallery Teaser เป็นปุ่มและเรียก `onFullReport`
- Style test ยืนยันว่าแถบล่างใช้ Grid และไม่มี Margin ติดลบสำหรับการซ้อนกับข้อความ
- Playwright ตรวจว่าไม่เกิดการทับกันที่ความกว้าง 375, 768, 1440, 1672 และ 1920 พิกเซล
- ตรวจว่า Gallery Teaser เปิดฟอร์มรับข้อมูลฉบับเต็มได้ และหน้าไม่มี Horizontal Overflow
