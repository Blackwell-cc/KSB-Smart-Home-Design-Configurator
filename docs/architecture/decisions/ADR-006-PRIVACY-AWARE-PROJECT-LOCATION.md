# ADR-006: ใช้จังหวัดและคำถามสภาพการเข้าถึงก่อน Preview

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-08-07
- ผู้ตัดสินใจ: Product Owner

## บริบท

ทำเลมีผลต่อราคาวัสดุ ค่าแรง และการขนส่ง แต่การขอที่อยู่หรือพิกัดที่ดินอย่างละเอียดก่อนผู้ใช้ได้รับคุณค่าอาจสร้างความกังวลด้านความเป็นส่วนตัวและทำให้ขั้นตอนใช้งานหนักเกินไป อีกทั้งข้อมูลรายจังหวัดมีแหล่งอ้างอิงที่นำมาสร้างตัวปรับราคาได้แล้ว

## การตัดสินใจ

ก่อนแสดง Free Preview ระบบจะขอข้อมูลทำเลดังนี้:

1. จังหวัด: บังคับเลือก
2. อำเภอหรือเขต: ไม่บังคับ
3. สภาพการเข้าถึงและข้อจำกัดหน้างาน: ใช้ตัวเลือกแบบกดเลือก
4. ที่อยู่เต็ม พิกัด หรือหมุดที่ดิน: ไม่ขอก่อน Preview

ตัวอย่างคำถามสภาพหน้างาน:

- รถบรรทุกและรถโม่เข้าถึงได้ตามปกติหรือไม่
- ที่ดินเป็นพื้นที่ราบ ลาดชัน หรือยังไม่แน่ใจ
- อยู่บนเกาะหรือพื้นที่ที่ต้องขนส่งพิเศษหรือไม่
- มีข้อจำกัดด้านความกว้างถนนหรือช่วงเวลาขนส่งหรือไม่

## หลักการคำนวณ

- ใช้จังหวัดเลือก Province Factor จาก Price Book เวอร์ชันที่ผ่านการตรวจรับ
- ยังไม่ใช้ระดับอำเภอหรือเขตปรับราคา จนกว่าจะมีข้อมูลที่น่าเชื่อถือและผ่านการ Calibrate
- ใช้คำตอบเรื่องการเข้าถึงเพื่อเพิ่ม Allowance หรือขยายช่วงราคา ไม่สร้างตัวเลขแม่นยำเกินข้อมูล
- หากผู้ใช้เลือก “ไม่แน่ใจ” ระบบต้องแสดง Site Logistics เป็นรายการรอตรวจสอบ
- ที่อยู่หรือพิกัดจริงสามารถขอภายหลังเมื่อผู้ใช้เลือกปรึกษาสถาปนิกและมีเหตุผลในการใช้งานที่ชัดเจน

## หลักความเป็นส่วนตัวและการแชร์

- จังหวัดเป็นข้อมูลโครงการ ไม่ผูกกับข้อมูลติดต่อจนกว่าผู้ใช้จะส่ง Lead
- Public Preview สามารถแสดงเพียงจังหวัดเมื่อผู้ใช้ยินยอม หรือไม่แสดงทำเลเลยเป็นค่าเริ่มต้น
- ห้ามนำอำเภอ เขต ที่อยู่ พิกัด หรือข้อมูลสภาพที่ดินไปแสดงใน Public Preview
- ข้อมูลตำแหน่งละเอียดที่เก็บภายหลังต้องไม่ถูกนำไปใช้เพื่อวัตถุประสงค์อื่นโดยไม่มีคำอธิบายและ Consent ที่เหมาะสม

## เหตุผล

- ลดจำนวนข้อมูลที่ต้องกรอกก่อนเห็นผล
- รักษาความน่าเชื่อถือและลดความรู้สึกว่าเป็น Lead Trap
- จังหวัดเพียงพอสำหรับเลือกฐานราคาพื้นที่ระดับแรก
- คำถามสภาพการเข้าถึงช่วยสะท้อนความเสี่ยงที่ตัวคูณจังหวัดเพียงอย่างเดียวไม่ครอบคลุม

## ผลตามมา

- Domain Model ต้องแยก `province`, `district_optional`, `site_access_profile` และข้อมูลที่อยู่ละเอียด
- Pricing Engine ต้องแยก `province_factor` ออกจาก `site_logistics_allowance`
- Report ต้องอธิบายเมื่อ Logistics Allowance ยังเป็นรายการรอตรวจสอบ
- Share Payload ต้องใช้ Allowlist และไม่มีฟิลด์อำเภอ ที่อยู่ พิกัด หรือ Site Access

## ตัวเลือกที่ไม่เลือก

- บังคับจังหวัดและอำเภอ: เพิ่มภาระก่อน Preview แต่ยังไม่ได้เพิ่มความแม่นยำหากไม่มีฐานราคาระดับอำเภอที่ตรวจรับแล้ว
- บังคับปักหมุดที่ดิน: ละเอียดเกินความจำเป็นสำหรับ Free Preview และเพิ่มความเสี่ยงด้านความเป็นส่วนตัว
