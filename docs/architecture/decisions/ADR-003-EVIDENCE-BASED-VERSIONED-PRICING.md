# ADR-003: ใช้ฐานราคาจากหลายแหล่งแบบมีเวอร์ชันและผ่านการตรวจรับ

- สถานะ: ยอมรับในหลักการ; รอตรวจรับตัวเลข
- วันที่: 2026-08-07
- ผู้ตัดสินใจ: Product Owner

## บริบท

KSB ยังไม่มีฐานข้อมูลราคาโครงการที่จัดโครงสร้างพร้อมใช้กับระบบ แต่ผลิตภัณฑ์ต้องประมาณการจากพื้นที่ จังหวัด ระดับวัสดุ ราคาก่อสร้าง และค่าออกแบบให้ใกล้เคียงความจริงที่สุด โดยต้องคงความน่าเชื่อถือและไม่สร้างความเข้าใจผิดว่าเป็นใบเสนอราคาหรือ BOQ

## การตัดสินใจ

ระบบจะใช้ Pricing Engine ที่อ้างอิงข้อมูลหลายระดับ:

1. Benchmark ค่าก่อสร้างบ้านจากแหล่งอุตสาหกรรม
2. ดัชนีค่าก่อสร้างบ้านและดัชนีราคาวัสดุเพื่อปรับตามเวลา
3. ราคาวัสดุ ค่าแรง และค่าขนส่งรายจังหวัดเพื่อปรับพื้นที่
4. ข้อมูลใบเสนอราคา สัญญา และราคาจบจริงของ KSB สำหรับ Calibrate
5. การตรวจรับโดยสถาปนิกหรือผู้ประมาณราคาก่อนเผยแพร่ Price Book

ทุกผลการคำนวณต้องผูกกับ Price Book เวอร์ชันหนึ่งเสมอ ระบบจะไม่เรียกแหล่งข้อมูลภายนอกแบบสดระหว่างการคำนวณของผู้ใช้

## หลักความน่าเชื่อถือ

- แยกตัวเลขจากแหล่งอ้างอิงออกจากสมมติฐานของ KSB
- แสดงช่วงราคา ไม่แสดงความแม่นยำเกินข้อมูลที่มี
- ระบุฐานพื้นที่ รายการที่รวม รายการที่ไม่รวม วันที่อ้างอิง และระดับความเชื่อมั่น
- ตัวคูณทุกตัวต้องมีเจ้าของ แหล่งที่มา วันที่อนุมัติ และประวัติการเปลี่ยนแปลง
- ฐานราคาใหม่ต้องผ่าน Backtest ก่อนแทนฐานราคาเดิม

## เหตุผล

- ใช้ข้อมูลราชการเพื่อสะท้อนการเปลี่ยนแปลงตามเวลาและความแตกต่างรายจังหวัด
- ใช้ Benchmark อุตสาหกรรมเพื่อให้มีจุดตั้งต้นที่สัมพันธ์กับบ้านระดับ High End
- ใช้ข้อมูลจริงของ KSB เพื่อปรับสูตรให้ตรงกับประเภทงาน ลูกค้า และผู้รับเหมาที่บริษัททำงานด้วย
- การมีเวอร์ชันทำให้ตรวจสอบ แก้ไข และอธิบายผลลัพธ์ย้อนหลังได้

## ผลตามมา

- ต้องมีขั้นตอน Data Refresh, Validation, Expert Approval และ Publish Price Book
- ต้องเพิ่ม `pricing_version`, `province_factor_version`, `reference_date` และ `confidence_level` ใน Domain Model
- ต้องสร้างหน้าหรือเครื่องมือภายในสำหรับตรวจผล Backtest ก่อนอัปเดตฐานราคา
- ตัวเลข Material Level และค่าออกแบบใน Research Baseline ยังห้ามถือเป็น Production Rate จนกว่าจะผ่านการตรวจรับของ KSB

## ตัวเลือกที่ไม่เลือก

- ใช้ราคาต่อตารางเมตรตัวเลขเดียวทั่วประเทศ: ไม่สะท้อนจังหวัด วัสดุ และความซับซ้อน
- เรียก API ภาครัฐแบบสดทุกครั้ง: เพิ่มความเสี่ยงด้านความเสถียรและทำให้ผลลัพธ์เปลี่ยนโดยไม่ผ่านการตรวจรับ
- ใช้เฉพาะข้อมูลตลาดภายนอก: ไม่สะท้อนขอบเขตงานและมาตรฐานจริงของ KSB
