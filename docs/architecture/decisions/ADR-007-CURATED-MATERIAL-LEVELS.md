# ADR-007: ใช้ Material Level แบบ Curated 3 ระดับใน MVP

- สถานะ: ยอมรับแล้ว
- วันที่: 2026-08-07
- ผู้ตัดสินใจ: Product Owner

## บริบท

ระดับวัสดุมีผลโดยตรงต่อราคาก่อสร้าง แต่การบังคับให้ผู้ใช้เลือกวัสดุทุกหมวดตั้งแต่ต้นจะทำให้ Configurator ยาวและต้องอาศัยความรู้เฉพาะทาง ขณะเดียวกัน การใช้คำว่า “มาตรฐาน–กลาง–หรู” โดยไม่มีตัวอย่างทำให้ผู้ใช้ตีความไม่ตรงกันและลดความน่าเชื่อถือของราคา

## การตัดสินใจ

MVP จะให้ผู้ใช้เลือก Material Level หลักหนึ่งระดับสำหรับทั้งโครงการ:

1. **Select — คุณภาพดี คุมงบอย่างมีมาตรฐาน**
2. **Premium — สมดุลความสวยและรายละเอียด**
3. **Signature — วัสดุและรายละเอียดเฉพาะบุคคล**

แต่ละระดับต้องมี:

- ภาพหรือ Material Mood ที่ผ่านการคัดเลือกโดย KSB
- คำอธิบายสั้นที่ผู้ใช้ทั่วไปเข้าใจได้
- ตัวอย่างคุณลักษณะของวัสดุและงานติดตั้ง ไม่สร้างความคาดหวังว่าได้รับยี่ห้อหรือรุ่นตามภาพ
- รายละเอียดแบบกดขยาย แยกอย่างน้อยเป็นพื้น ผนัง หลังคา ประตูและหน้าต่าง สุขภัณฑ์ และงานระบบ
- ช่วงราคาต่อตารางเมตรที่ผูกกับ Price Book เวอร์ชัน

รายละเอียดรายหมวดใน MVP ใช้เพื่ออธิบายและเปรียบเทียบ ผู้ใช้ยังไม่ผสมระดับวัสดุข้ามหมวดในสูตรหลัก

## หลักการ UX และ Content

- ไม่ใช้คำที่ทำให้ Select ดูราคาถูกหรือคุณภาพต่ำ
- ใช้ภาพจริงหรือภาพอ้างอิงที่มีสิทธิ์ใช้งาน และติดป้ายว่าเป็นภาพบรรยากาศหรือตัวอย่างแนวทาง
- แสดงความแตกต่างที่มีผลต่อคุณภาพ อายุใช้งาน การดูแล และรายละเอียดติดตั้ง ไม่เน้นเพียงความแพง
- เมื่อเลือกระดับแล้ว Summary ต้องย้ำสิ่งที่ระดับนั้นหมายถึง
- หากผู้ใช้เลือก Signature ให้แจ้งว่าราคาอาจเกินช่วงเมื่อมีวัสดุนำเข้า งานสั่งทำ หรือระบบเฉพาะ
- ห้ามรับประกันยี่ห้อ รุ่น สี หรือวัสดุเฉพาะก่อนเข้าสู่กระบวนการออกแบบและจัดทำ Specification

## หลักการคำนวณ

- Material Level แต่ละระดับอ้างอิง Rate Range ไม่ใช่ตัวเลขจุดเดียว
- Rate Range ต้องแยกจาก Complexity Factor และ Special Feature Allowance
- ตัวเลข Select และ Signature ต้องผ่านการ Calibrate ด้วยข้อมูลจริงของ KSB ก่อนใช้ใน Production
- การเปลี่ยนคำอธิบายที่มีผลต่อความหมายของระดับวัสดุต้องสร้าง `material_level_version` ใหม่

## เหตุผล

- รักษาประสบการณ์แบบกดเลือกง่าย
- ช่วยให้ผู้ใช้เข้าใจสิ่งที่อยู่เบื้องหลังราคามากกว่าการเห็นตัวเลขอย่างเดียว
- สอดคล้องกับภาพลักษณ์มืออาชีพและ Calm Luxury ของ KSB
- ลดความคลาดเคลื่อนจากการตีความคำว่า “วัสดุมาตรฐาน” หรือ “วัสดุพรีเมียม” ต่างกัน

## ผลตามมา

- Domain Model ต้องมี `material_level_id`, `material_level_version` และ `material_rate_range`
- ต้องจัดทำ Material Mood และคำอธิบายที่ผ่านการตรวจรับทั้ง 3 ระดับ
- Report ต้องแสดง Material Level พร้อมสิ่งที่รวม สมมติฐาน และข้อจำกัด
- การผสมระดับวัสดุรายหมวดเป็นฟีเจอร์หลัง MVP หากข้อมูลการคำนวณรองรับ

## ตัวเลือกที่ไม่เลือก

- เลือกวัสดุทุกหมวดก่อน Preview: แม่นขึ้นในบางกรณี แต่ขั้นตอนยาวและสร้างภาระสูงเกิน MVP
- ให้ระบบเลือกระดับจากงบประมาณโดยไม่ถามผู้ใช้: ลดการควบคุมและอาจไม่สะท้อนความสำคัญที่แท้จริงของเจ้าของบ้าน
